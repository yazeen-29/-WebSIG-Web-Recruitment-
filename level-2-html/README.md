# WHAT HTML DOES?
HTML IS USED TO STRUCTURE THE CONTENT OF A WEBPAGE.
IT TELLS THE BROWSER WHAT EACH CONTENT IS, LIKE WHICH IS HEADING, PARAGRAPH ETC..

# Tags vs Elements
tag is syntax like <p>or</p>
but if its a complete unit like <p>hello world</p>

# head vs body
head contains metadata like title of the page ,charector set,viewport etc. its not visible 
body contains the visible part of the webpage ie,text,image ,list, button etc

# Differece between div and semantic tags
<div> is just a container no meaning but semantic tags like <header>,<main> etc describe the meaning of the content
