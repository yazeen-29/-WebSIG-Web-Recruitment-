# Git & GitHub Basics (Level 1)

## What is Git?
Git is a distributed version control system that tracks changes in code over time.  
It allows developers to create checkpoints (commits), compare changes, revert to previous versions, and collaborate safely without overwriting each other's work.

## What is GitHub?
GitHub is a cloud platform that hosts Git repositories online.  
It helps developers store code remotely, collaborate through pull requests, review code, manage issues, and share projects publicly or privately.

## Why do developers use Git + GitHub?
- Track the full history of a project  
- Work in teams without overwriting each other's code  
- Backup projects online  
- Use branches to build features safely  
- Collaborate using pull requests and code reviews  
- Contribute to open-source projects
